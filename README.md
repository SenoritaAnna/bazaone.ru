# БАЗА — корпоративный сайт (Hero)

Первый экран (Hero) корпоративного сайта БАЗА. Чистый HTML/CSS/JS, **без фреймворков и библиотек**.

## Механика (принцип enso, не копия)

Подложка на весь экран — **текстура чёрной кожи крокодила**. Hero закреплён (`sticky`), сцены сменяются по скроллу:

1. **Первый экран** — только иконки **Артём & Анна** (белый лайн-арт, сквозь силуэт видна кожа).
2. **Скролл** — иконки **съезжают влево**, затем **справа налево выезжает** гигантское **«БАЗА»** (шрифт **Playfair Display 900**), синхронно со скроллом (scrub, не marquee).
3. После этого Hero плавно отдаёт управление секции `#after-hero`. Без бесконечного скролла, **без фото — только иконки**.

`prefers-reduced-motion`: те же сцены статично, без движения. Поддержаны клавиатура (skip-link, обычный скролл) и контраст.

## Структура

```
САЙТ/
├── index.html                     # разметка Hero + следующая секция
├── css/hero.css                   # стили, @font-face, фон-крокодил, reduced-motion, мобилка
├── js/hero.js                     # контроллер pin+scrub (rAF)
├── assets/
│   ├── crocodile.jpg              # оптимизированная текстура-подложка (312 КБ)
│   ├── icon-artem.png             # иконка Артём (прозрачный белый лайн-арт)
│   ├── icon-anna.png              # иконка Анна
│   ├── partners-placeholder.svg   # больше НЕ используется (остался от прошлой версии)
│   └── fonts/
│       ├── playfair-cyr.woff2     # Playfair Display 900 (кириллица) — для «БАЗА»
│       └── unbounded-*.woff2      # Unbounded — бренд/UI
└── ИКОНКИ/                        # исходники от Анны (оригиналы иконок + текстура PNG)
```

## Локальный предпросмотр

Из папки `САЙТ/`:

```bash
python3 -m http.server 5178
```

Открыть: **http://127.0.0.1:5178/**  (нужен http-сервер, не открытие файла напрямую).

## Как заменить ассеты

- **Иконки** — исходники в `ИКОНКИ/` (белые/чёрные версии). Рабочие прозрачные PNG лежат в `assets/icon-artem.png` / `assets/icon-anna.png`. Чтобы обновить: положи новый白 лайн-арт на чёрном фоне и пересобери прозрачную версию (альфа = яркость), либо дай готовый прозрачный PNG в `assets/` под тем же именем.
- **Текстура фона** — `assets/crocodile.jpg`. Заменить на другой JPEG того же имени (держать вес ≲ 350 КБ).
- **Слово** — «БАЗА» в `index.html` (сцена `scene--type`). Шрифт — `Playfair Display` (в `css/hero.css`).
